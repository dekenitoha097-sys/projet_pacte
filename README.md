## Stack Technique
* **Base de données :** MariaDB
* **Backend (S1) & IA (S2) :** Python (FastAPI/Flask) + Scikit-learn
* **Frontend :** React

## Le Projet
Plateforme B2B permettant aux agriculteurs de monitorer le stress hydrique de leurs parcelles. Intégration en temps réel des données Open-Meteo, moteur de règles agronomiques, et prédictions de rendement via IA (Semestre 2).
